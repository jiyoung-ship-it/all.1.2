
# 나만의 Python 퀴즈 게임

## 1. 프로젝트 소개

Python으로 제작한 터미널 기반 객관식 퀴즈 게임입니다.

사용자는 기본으로 제공되는 퀴즈를 풀거나
직접 새로운 퀴즈를 추가할 수 있습니다.

퀴즈 결과는 100점 만점으로 계산하며,
최고 점수와 직접 추가한 문제는 JSON 파일에 저장됩니다.

### 개발 목적

- Python의 기본 문법과 입출력 이해
- 조건문, 반복문, 함수 활용
- 클래스와 객체지향 프로그래밍 적용
- JSON 파일을 활용한 데이터 영속성 구현
- Git과 GitHub를 활용한 버전 관리 실습

## 2. 퀴즈 주제 및 선정 이유

### 주제: Python 기초 프로그래밍

Python을 처음 배우는 학습자가 기본 개념을
복습할 수 있도록 Python 기초 문법을 주제로 선정했습니다.

출력 함수, 자료형, 조건문, 함수 정의,
리스트 등의 개념을 객관식 문제로 구성했습니다.

기본 문제는 총 5개이며,
사용자가 새로운 문제를 추가할 수 있습니다.

## 3. 개발 환경

- 개발 언어: Python 3.14
- 개발 도구: Visual Studio Code
- 운영체제: macOS
- 버전 관리: Git
- 원격 저장소: GitHub
- 외부 라이브러리: 없음 (Python 표준 라이브러리 사용)

Python 3.10 이상에서 실행할 수 있도록 작성했습니다.

## 4. 주요 기능

### 4.1 퀴즈 풀기

- 등록된 객관식 문제를 순서대로 출제
- 문제마다 4개의 선택지 제공
- 1~4번 중 정답 입력
- 정답과 오답 판정
- 정답 개수 및 최종 점수 출력
- 최고 점수 자동 갱신

### 4.2 퀴즈 추가하기

- 새로운 문제 직접 입력
- 선택지 4개 입력
- 정답 번호 1~4 입력
- 입력값 검증
- 추가한 문제를 JSON 파일에 저장

### 4.3 퀴즈 목록 보기

- 기본 퀴즈와 추가한 퀴즈 출력
- 문제 및 선택지 확인
- 정답 번호 확인

### 4.4 최고 점수 확인

- 퀴즈 완료 후 최고 점수 기록
- 기존 최고 점수보다 높으면 갱신
- JSON 파일에 저장하여 재실행 후에도 유지

### 4.5 종료

- 메뉴에서 5번을 입력하면 정상 종료

## 5. 프로젝트 파일 구조

```text
all.1.2/
├── main.py
├── quiz.py
├── quiz_data.py
├── quiz_game.py
├── state.json
├── .gitignore
└── README.md
```

### 파일별 역할

| 파일 | 설명 |
|------|------|
| main.py | 프로그램 실행 시작점 |
| quiz.py | Quiz 클래스 및 정답 판정 |
| quiz_data.py | 기본 퀴즈 5개 제공 |
| quiz_game.py | QuizGame 클래스 및 게임 전체 기능 |
| state.json | 추가한 퀴즈와 최고 점수 저장 |
| .gitignore | Git 추적 제외 파일 설정 |
| README.md | 프로젝트 설명 및 실행 안내 |

※ state.json은 프로그램에서 데이터를 저장하면
자동으로 생성되며 GitHub에는 업로드하지 않습니다.

## 7. JSON 데이터 저장 방식

프로그램은 프로젝트 폴더의
state.json 파일에 데이터를 저장합니다.

### 저장 데이터 예시

```json
{
    "custom_quizzes": [
        {
            "question": "Python에서 함수를 정의하는 키워드는?",
            "choices": [
                "class",
                "def",
                "import",
                "return"
            ],
            "answer": 2
        }
    ],
    "best_score": 80.0
}
```

### 데이터 구성

| 항목 | 의미 |
|------|------|
| custom_quizzes | 사용자가 추가한 퀴즈 목록 |
| question | 문제 내용 |
| choices | 4개의 선택지 |
| answer | 정답 번호(1~4) |
| best_score | 최고 점수(0~100) 또는 null |

### 저장 및 불러오기

- 프로그램 시작 시 state.json을 읽습니다.
- 저장 파일이 없으면 기본 퀴즈로 시작합니다.
- 파일 내용이 잘못된 경우 오류 메시지를 출력하고 기본 데이터로 시작합니다.
- 새로운 퀴즈를 추가하면 저장합니다.
- 최고 점수가 갱신되면 저장합니다.
- UTF-8 인코딩으로 한글 데이터를 처리합니다.

## 8. 입력값 검증 및 예외 처리

- 메뉴 번호는 1~5만 허용합니다.
- 정답 번호는 1~4만 허용합니다.
- 문제와 선택지의 빈 문자열을 허용하지 않습니다.
- 잘못된 숫자나 문자 입력을 처리합니다.
- Ctrl+C 및 EOF 입력을 처리합니다.
- JSON 파일 누락, 손상 및 파일 입출력 오류를 처리합니다.

## 9. 객체지향 설계

### Quiz 클래스

퀴즈 문제 하나를 관리합니다.

- question: 문제 내용
- choices: 선택지 4개
- answer: 정답 번호
- display(): 문제와 선택지 출력
- check_answer(): 정답 판정

### QuizGame 클래스

퀴즈 게임 전체를 관리합니다.

- quizzes: 등록된 퀴즈 목록
- best_score: 최고 점수
- run(): 메인 메뉴 실행
- play_quiz(): 퀴즈 진행
- add_quiz(): 문제 추가
- show_quiz_list(): 목록 출력
- show_best_score(): 최고 점수 출력
- save_state(): JSON 데이터 저장
- load_state(): JSON 데이터 불러오기
