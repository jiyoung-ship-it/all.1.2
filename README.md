
# 나만의 Python 퀴즈 게임

## 1. 프로젝트 소개

Python으로 제작한 터미널 기반 객관식 퀴즈 게임입니다.

사용자는 기본으로 제공되는 퀴즈를 풀거나 직접 새로운 퀴즈를 추가할 수 있습니다.

퀴즈 문제는 무작위 순서로 출제되며, 사용자가 풀 문제 개수를 선택할 수 있습니다.

퀴즈 결과는 100점 만점으로 계산하고, 힌트를 사용하면 해당 문제의 획득 점수가 감소합니다.

전체 퀴즈 목록, 최고 점수, 풀이 기록은 JSON 파일에 저장되어 프로그램을 종료하고 다시 실행해도 유지됩니다.

### 개발 목적

- Python의 기본 문법과 입출력 이해
- 조건문, 반복문, 함수 활용
- 클래스와 객체지향 프로그래밍 적용
- JSON 파일을 활용한 데이터 영속성 구현
- 입력값 검증과 예외 처리 학습
- Git과 GitHub를 활용한 버전 관리 실습

## 2. 퀴즈 주제 및 선정 이유

### 주제: Python 기초 프로그래밍

Python을 처음 배우는 학습자가 기본 개념을 복습할 수 있도록 Python 기초 문법을 주제로 선정했습니다.

출력 함수, 자료형, 조건문, 함수 정의, 리스트 등의 개념을 객관식 문제로 구성했습니다.

기본 문제는 총 5개이며, 사용자가 새로운 문제를 추가하거나 기존 문제를 삭제할 수 있습니다.

## 3. 개발 환경

- 개발 언어: Python 3.14
- 개발 도구: Visual Studio Code
- 운영체제: macOS
- 버전 관리: Git
- 원격 저장소: GitHub
- 외부 라이브러리: 없음
- 사용 라이브러리: json, random, datetime, pathlib (Python 표준 라이브러리)

Python 3.10 이상에서 실행할 수 있도록 작성했습니다.

## 4. 주요 기능

### 4.1 퀴즈 풀기

- 등록된 객관식 문제를 무작위 순서로 출제
- 사용자가 풀 문제 개수 선택
- 문제마다 4개의 선택지 제공
- 1~4번 중 정답 입력
- 정답과 오답 판정
- 정답 개수 및 최종 점수 출력
- 최고 점수 자동 갱신
- 등록된 퀴즈가 없는 경우 안내 메시지 출력

### 4.2 퀴즈 추가하기

- 새로운 문제 직접 입력
- 선택지 4개 입력
- 정답 번호 1~4 입력
- 힌트 선택 입력
- 입력값 검증
- 추가한 문제를 JSON 파일에 저장

### 4.3 퀴즈 목록 보기

- 기본 퀴즈와 추가한 퀴즈 출력
- 문제 및 선택지 확인
- 정답 번호 확인
- 등록된 힌트 확인
- 퀴즈가 없는 경우 안내 메시지 출력

### 4.4 최고 점수 확인

- 퀴즈 완료 후 최고 점수 기록
- 기존 최고 점수보다 높으면 갱신
- JSON 파일에 저장하여 재실행 후에도 유지
- 기록이 없는 경우 안내 메시지 출력

### 4.5 퀴즈 삭제하기

- 등록된 퀴즈 목록 출력
- 삭제할 문제 번호 선택
- 삭제 전 확인 메시지 출력
- 삭제한 내용을 JSON 파일에 반영
- 삭제 취소 기능 제공

### 4.6 풀이 기록 보기

- 퀴즈를 완료할 때마다 풀이 기록 저장
- 날짜 및 시간 기록
- 푼 문제 수와 정답 개수 기록
- 힌트 사용 횟수 기록
- 최종 점수 기록
- 프로그램 재실행 후에도 기록 유지

### 4.7 종료

- 메뉴에서 7번을 입력하면 정상 종료
- 종료 시 JSON 데이터 저장 시도
- Ctrl+C 및 EOFError 발생 시 안내 메시지 출력
- 가능한 범위에서 데이터를 저장하고 안전하게 종료

## 5. 보너스 기능

### 5.1 랜덤 출제

random.sample()을 사용하여 문제를 중복 없이 무작위로 선택합니다.

### 5.2 문제 수 선택

등록된 퀴즈 수를 기준으로 사용자가 풀 문제 개수를 선택할 수 있습니다.

### 5.3 힌트 기능

Quiz 클래스에 hint 속성을 추가했습니다.

- 힌트가 등록된 문제는 해당 힌트 출력
- 힌트가 없는 문제는 오답 선택지 2개 제거
- 문제당 힌트 1회 사용 가능
- 힌트 없이 정답: 100점
- 힌트 사용 후 정답: 50점
- 오답: 0점

최종 점수는 선택한 문제 수를 기준으로 100점 만점으로 계산합니다.

### 5.4 퀴즈 삭제

사용자가 등록된 퀴즈를 삭제할 수 있습니다.

삭제 결과는 JSON 파일에 반영되며, 프로그램을 재실행해도 유지됩니다.

### 5.5 점수 기록 히스토리

datetime 모듈을 사용하여 퀴즈 완료 날짜와 시간을 기록합니다.

모든 완료된 게임의 점수를 저장하고, 메뉴에서 이전 기록을 조회할 수 있습니다.

### 파일별 역할

| 파일 | 설명 |
|------|------|
| main.py | 프로그램 실행 시작점 |
| quiz.py | Quiz 클래스, 문제 데이터 및 힌트 관리 |

| quiz_game.py | QuizGame 클래스 및 게임 전체 기능 |
| state.json | 퀴즈, 힌트, 최고 점수, 풀이 기록 저장 |
| .gitignore | Git 추적 제외 파일 설정 |
| README.md | 프로젝트 설명 및 실행 안내 |

state.json은 프로그램에서 데이터를 저장하면 자동으로 생성되며, GitHub에는 업로드하지 않습니다.

## 8. JSON 데이터 저장 방식

프로그램은 프로젝트 루트의 state.json 파일에 데이터를 저장합니다.

파일 인코딩은 UTF-8이며, 한글 데이터도 저장할 수 있습니다.

### 저장 데이터 예시

```json
{
    "quizzes": [
        {
            "question": "Python에서 함수를 정의하는 키워드는?",
            "choices": [
                "class",
                "def",
                "import",
                "return"
            ],
            "answer": 2,
            "hint": "함수를 정의할 때 사용하는 키워드입니다."
        }
    ],
    "best_score": 80.0,
    "history": [
        {
            "date": "2026-11-12 14:30:25",
            "total": 5,
            "correct": 4,
            "hints_used": 0,
            "score": 80.0
        }
    ]
}
```

위 데이터는 저장 형식을 설명하기 위한 예시입니다.

실제 state.json에는 현재 등록된 모든 퀴즈와 완료된 게임 기록이 저장됩니다.

### 데이터 구성

| 항목 | 의미 |
|------|------|
| quizzes | 현재 등록된 전체 퀴즈 목록 |
| question | 문제 내용 |
| choices | 4개의 선택지 |
| answer | 정답 번호(1~4) |
| hint | 힌트 내용 또는 null |
| best_score | 최고 점수(0~100) 또는 null |
| history | 완료된 퀴즈 풀이 기록 목록 |
| date | 퀴즈 완료 날짜와 시간 |
| total | 푼 문제 수 |
| correct | 정답 개수 |
| hints_used | 힌트 사용 횟수 |
| score | 해당 게임의 최종 점수 |

### 저장 및 불러오기

- 프로그램 시작 시 state.json을 읽습니다.
- 저장 파일이 없으면 기본 퀴즈로 시작합니다.
- 파일 내용이 손상된 경우 오류 메시지를 출력하고 기본 데이터로 시작합니다.
- 새로운 퀴즈를 추가하면 저장합니다.
- 퀴즈를 삭제하면 저장합니다.
- 퀴즈를 완료하면 최고 점수와 풀이 기록을 저장합니다.
- 프로그램 종료 시에도 저장을 시도합니다.
- UTF-8 인코딩으로 한글 데이터를 처리합니다.
- 이전 버전의 JSON 데이터 형식도 불러올 수 있도록 구현했습니다.

## 9. 입력값 검증 및 예외 처리

- 메뉴 번호는 1~7만 허용합니다.
- 정답 번호는 1~4만 허용합니다.
- 문제 개수는 등록된 퀴즈 수 범위 내에서 선택합니다.
- 입력값 앞뒤 공백을 제거합니다.
- 빈 입력에 대한 안내 메시지를 출력합니다.
- 잘못된 숫자나 문자 입력을 처리합니다.
- 문제와 선택지의 빈 문자열을 허용하지 않습니다.
- Ctrl+C 및 EOFError 입력을 처리합니다.
- JSON 파일 누락, 손상 및 파일 입출력 오류를 처리합니다.
- 프로그램 종료 시 가능한 범위에서 데이터를 저장합니다.

## 10. 객체지향 설계

### Quiz 클래스

퀴즈 문제 하나를 관리합니다.

속성:

- question: 문제 내용
- choices: 선택지 4개
- answer: 정답 번호
- hint: 선택적으로 등록한 힌트

메서드:

- __init__(): 문제 데이터 초기화 및 검증
- display(): 문제와 선택지 출력
- check_answer(): 정답 판정
- get_hint(): 등록된 힌트 반환

### QuizGame 클래스

퀴즈 게임 전체를 관리합니다.

속성:

- quizzes: 등록된 퀴즈 목록
- best_score: 최고 점수
- history: 퀴즈 풀이 기록

주요 메서드:

- run(): 메인 메뉴 실행
- show_menu(): 메뉴 출력
- get_menu_choice(): 메뉴 입력 처리
- get_answer(): 정답 번호 입력 처리
- get_quiz_count(): 문제 수 선택
- get_answer_with_hint(): 힌트 사용 및 정답 입력
- play_quiz(): 퀴즈 진행
- add_quiz(): 문제 추가
- show_quiz_list(): 목록 출력
- delete_quiz(): 문제 삭제
- show_best_score(): 최고 점수 출력
- show_history(): 풀이 기록 출력
- save_state(): JSON 데이터 저장
- load_state(): JSON 데이터 불러오기

## 13. Git Clone 및 Pull 실습

GitHub 저장소를 별도 폴더에 복제했습니다.

복제한 프로젝트에서 README.md를 수정한 뒤 GitHub에 변경 사항을 업로드했습니다.

이후 원래 프로젝트에서 git pull을 실행하여 최신 변경 사항이 반영되는지 확인했습니다.

이를 통해 원격 저장소의 변경 사항을 다른 로컬 작업 디렉터리로 가져오는 과정을 학습했습니다.

## 14. Git 브랜치 병합 검증

별도의 작업 브랜치에서 문서를 수정하고 커밋한 후, main 브랜치로 병합하여 Git 협업 과정을 검증했습니다.

병합 시 --no-ff 옵션을 사용하여 브랜치 병합 이력이 Git 그래프에 남도록 했습니다.
